# Architecture contract

This file is project-specific and should be completed before the first
implementation feature is started.

Document:

- the main components and their responsibilities;
- allowed dependencies and integration boundaries;
- data ownership and persistence rules;
- error-handling expectations;
- interfaces that must remain stable.

Agents must treat this document as the architecture decision record for the
generated project. If a feature requires a new component or dependency, add
that decision to `feature_list.json` before implementation.
